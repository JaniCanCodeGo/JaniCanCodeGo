# Module 1: HTML Basics

**What you'll have built by the end:** a one-page personal site with a heading, some text about you, a link, and an image — live in your own browser.

## Why this module exists

You don't need a computer science degree to build a web page. You need to know what a handful of tags mean and that it's genuinely okay to break things while you learn. This module is the on-ramp — no prior experience assumed.

## What is HTML, really

HTML is just a set of labels that tell a browser what something is: "this is a heading," "this is a paragraph," "this is a link." That's it. You're not programming yet — you're labeling.

## What you'll build

1. A page with your name as a heading
2. A short paragraph about yourself
3. A link to something you care about
4. An image (yours or a placeholder)

## Common snag

The page looks like plain text with no styling — that's expected at this stage. Styling comes later. If your page shows the actual tags as text instead of formatting them, a tag is probably not closed correctly. That's not a sign you're bad at this — it's the single most common HTML mistake there is.

## Recap

By the end of this module you have a real, working web page you built yourself. Next module: getting it running locally instead of just opening a file.
