# Hosting Checklist — Before Every Workgroup Session

- [ ] Confirm which module we're on and reread your teaching-script prep
- [ ] Have one honest personal aside ready (real fog moment, real win — not a performance)
- [ ] Screen share tested, localhost demo already running before people join
- [ ] One "if you get stuck, ask Claude this" prompt ready per tricky step
- [ ] Grace reminder: it's fine if the session runs long, it's fine if someone's behind
- [ ] Recap message drafted for after the session (use `cetl_content_agent.py host --type teaching-script` or `audience --type assignment-recap`)
