EIN application details (only used if no EIN is found)

If the agent finds no EIN, it produces a completed IRS Form SS-4 document with a step-by-step filing guide. These fields let it fill in every line. Never enter a Social Security number anywhere in this app — the IRS collects that directly when you file.

Programs, merchandise, and focus

Drives the documented pain-point research in the needs statement.

Funding opportunity (makes the application submittable)

The agent extracts the funder's questions, page limits, deadlines, and scoring rubric, then writes an answer to each question — this is what makes the output an actual application instead of a generic narrative.

Local need data (reviewers weight this most)

These lead your needs statement, above national research. The results page links county-level data sources (Census QuickFacts, CDE DataQuest, kidsdata.org) if you need numbers.

Project budget (line items; auto-allocated from the request if blank)

Produces a funder-format line-item budget with a written justification and a funding-gap statement answering “why do you need this grant?”

Forecast assumptions (defaults used if blank)

Trademark

The agent runs a knockout search for identical and sound-alike marks and prepares a complete TEAS Plus packet. Filing itself happens at teas.uspto.gov with your signature — the USPTO has no third-party filing API. This tool is not legal advice.
