# House Style and Guardrails (apply to every deliverable)

1. NO EM-DASHES anywhere: not in documents, slides, form labels, code
   comments that render into documents, or generated prose. Use commas,
   colons, or separate sentences. This is a hard, build-blocking rule.
   Exception: verbatim quoted instrument language is reproduced exactly,
   including its original punctuation (those quotes use en dashes, not
   em dashes).
2. Tracked changes and authored edits are attributed to Murjani McTier,
   never Claude. Set docx author metadata accordingly.
3. Never invent a measurement. A value not present in the packet is
   missing: it goes in the Missing Information Report, never the LOF.
4. Evidence-request names and any quoted NOF or instrument language are
   verbatim from source. Never paraphrase (see references/boilerplate.md).
5. Legal authority and date boundaries are verified against the current
   instrument each cycle, not carried forward silently
   (see references/standards-matrix.md).
6. Stop and ask before assuming changed section counts, new legislation,
   Title IX rule status, or which standard applies when dates are
   ambiguous.
7. Fonts: Arial for Word deliverables (10 pt LOF table body, 12 pt guide
   body). The HTML tools use the CDE OEO palette: navy #1A2744, navy mid
   #243460, gold #C8A84B, gold light #E8D08A, cream #F7F4EE, sage #EDF0EB,
   border #D4CEBD, muted #6B6659; DM Serif Display headings, DM Sans body,
   DM Mono kickers.
8. Program Access is observational: the Program Reviewer determines it via
   the 14 Facilities / Maintenance and Operations interview questions. The
   site fills out the guide; the Program Reviewer makes the final
   compliance determination. The form captures data; it does not
   adjudicate.
9. The Standard column cites the standard applicable at construction or
   alteration (element by element). Corrective actions are ALWAYS cited to
   2010 ADA. Program Access rows read None. / None.
10. Filename conventions: site guide
    `Civil_Rights_Review_Building_Accessibility.docx` (titled "Civil
    Rights Review - Building Accessibility"); staff interview
    `Program_Access_Staff_Interview.docx`; letter
    `[SchoolName]_Facilities_LOF.docx`.
11. Site-facing documents carry NO internal reviewer content: no
    standard determination or era prompts, no reviewer rules, no
    Corrective Action Summary (LOF only), no "Instance N" labels. The
    LOF agent performs standard determination and explains it to the
    Program Reviewer in Standard_Determination_[School].md.
