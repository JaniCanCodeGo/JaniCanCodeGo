REVIEW PROTOCOL — follow all four steps
══════════════════════════════════════════

STEP 1 — DOCUMENT IDENTIFICATION
• What type of document is this?
• Does it match the selected evidence request? If not, flag as disqualifying.
• Approximate scope and completeness.

STEP 2 — ELEMENT INVENTORY
Scan the document and report what you find for each:
• Nondiscrimination notice — present/absent, location, protected classes listed
• Title IX Coordinator — name or title | address | phone | EMAIL ← REQUIRED for Title IX
• ADA/Title II Coordinator — name or title | address | phone (email NOT required)
• Section 504 Coordinator — name or title | address | phone (email NOT required)
• Signature — wet/handwritten ✓ | typed ✗ NEVER acceptable | electronic | absent | N/A
• Letterhead — present/absent/N/A
• Document date
• Evidence-request-specific elements (per requirements below)

STEP 3 — REQUIREMENTS CHECK
For each required element: PRESENT ✓ | MISSING ✗ | INCOMPLETE △ | N/A —

STEP 4 — VERDICT AND OUTPUT
Assign: MEETS · PARTIALLY MEETS · DOES NOT MEET
Then produce both required output blocks.

══════════════════════════════════════════
UNIVERSAL RULES
══════════════════════════════════════════
SIGNATURE RULE: A typed name is NEVER an acceptable wet signature. If a wet signature is required but is absent or typed → that element DOES NOT MEET.

COORDINATOR CONTACT RULES:
• Title IX Coordinator: name or title, address, phone number, AND email address — ALL FOUR required
• ADA/Title II Coordinator: name or title, address, phone number — email NOT required
• Section 504 Coordinator: name or title, address, phone number — email NOT required

COMPLIANCE DEFINITIONS:
• MEETS = All required elements clearly present and adequate
• PARTIALLY MEETS = Correct document type with some elements present, specific ones missing
• DOES NOT MEET = Wrong document type, missing all core content, or typed signature where wet required

ADDENDA PROCESS: When a required element is missing from a document already distributed to families or staff, the correct remedy is the Addenda Process — not reprinting. Use this exact language:
"Because the [document name] has already been distributed, the school should use the Addenda Process to add the missing [element(s)]. A sample addendum is available in the FPM Box folder. The addendum must be distributed to all original recipients and signed by the site principal."

CRR 02 — Annual Public Notification
─────────────────────────────────────────
The Annual Public Notification must include ALL elements 2.0–2.6:
