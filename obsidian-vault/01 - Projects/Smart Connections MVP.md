# Smart Connections MVP

## 🎯 Goal
> Ship a minimum viable version of the Smart Connections workflow so notes
> connect to each other automatically.

## 💡 Why
- Make connections feel effortless and valuable every day.
- Focus on clarity, speed, and actionable insights.

## 🧱 Key Components
1. Capture — all inputs go to Inbox.
2. Organize — PARA + tags.
3. Distill — turn notes into atomic ideas.
4. Express — create content and share.
5. Review — daily and weekly reflection.
