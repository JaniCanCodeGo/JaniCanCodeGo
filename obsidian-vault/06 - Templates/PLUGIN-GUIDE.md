# 🔌 Plugin & Workflow Guide

Every plugin, workflow, and advanced setup from the Snoopy slides, organized
so you can install at your own pace. Install community plugins via
**Settings → Community plugins → Browse**.

## Part 1 — The 10 best add-ons (Slides 4–5)

| Plugin | What it does |
|--------|--------------|
| Smart Connections | AI chat with all your notes; finds hidden links |
| Copilot | Clean AI chat inside Obsidian |
| Templater | Auto-fills new notes with structure |
| Dataview | Turns your vault into a searchable database |
| Tasks | Track to-dos across the whole vault |
| Calendar | Visual calendar for daily notes |
| Periodic Notes | Daily / weekly / monthly notes |
| Obsidian Git | Auto-backup your vault to GitHub |
| Kanban | Trello-style boards inside notes |
| QuickAdd | One-keystroke capture and note creation |

Also useful: Natural Language Dates, Advanced Tables, Style Settings, Excalidraw.

## Part 2 — 10 workflows that save hours (Slides 6–9)

1. **Meeting Processor** — messy notes in → structured action items out
   (use `Meeting Note Template.md`).
2. **Research Ingestion** — paste an article link → connected summary note.
3. **Weekly Review** — Claude scans your week → drafts your Friday summary
   (use `Weekly Review Template.md`).
4. **Idea Cross-Pollinator** — Claude finds connections between notes written
   months apart.
5. **Project Kickoff** — tell Claude your goals → it builds the full project
   folder (planning / research / assets / docs / tasks).
6. **Vault Health Check** — Claude finds messy/orphan notes monthly.
7. **Book Notes System** — connect highlights to existing knowledge.
8. **Argument Builder** — find all vault evidence for a thesis.
9. **Decision Journal** — spot your blind spots over time.
10. **Daily Synthesis** — turn the day's captures into permanent notes.

## Part 3 — 10 advanced setups for power users (Slides 10–13)

1. **CLAUDE.md** — ✅ already in your vault root. One file that tells Claude
   your structure, conventions, and projects. Edit it as your system grows.
2. **MCPVault** — a bridge connecting Claude directly to your vault (~14
   commands, low setup). See README step 3, Option B.
3. **Official Obsidian Skills** — `github.com/steph-ango/obsidian-skills`, a
   collection of practical Obsidian skills built by Obsidian's CEO. Optional.
4. **Nightly Routine** — have Claude run at night to process the Inbox, file
   notes, and create a morning summary. Wake up to a clean vault.
5. **Multi-Vault Strategy** — separate vaults for Personal / Work / Learning.
6. **Graph Analysis** — use the graph view + color groups to see clusters.
7. **Zettelkasten + AI** — Claude maps atomic notes into idea clusters.
8. **Vault-Powered Projects** — linked atomic notes Claude can reason through.
9. **Feedback Loop** — save Claude's outputs back into the vault so your
   knowledge compounds.
10. **Obsidian-Second-Brain** — the full command set for AI-driven operation.

> You don't need all 30 at once. Start with the 5 in the README, get Claude
> connected, and add the rest as you feel the need.
