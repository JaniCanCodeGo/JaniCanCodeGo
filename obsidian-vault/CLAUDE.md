# CLAUDE.md

This file provides guidance to Claude (claude.ai/code and the Obsidian
connector) when working with content in this Obsidian vault. Claude reads
it at the start of every session, so it always knows your context.

## Vault Structure

- `00 - Inbox/` — Capture everything here first. Process daily.
- `01 - Projects/` — Active projects with goals, tasks, and notes.
- `02 - Areas/` — Ongoing areas of responsibility (no end date).
- `03 - Resources/` — Topics, references, and learning materials.
- `04 - Notes/` — Notes split into types (see below).
- `05 - Archives/` — Completed or inactive items.
- `06 - Templates/` — Templates for notes and workflows.
- `07 - Attachments/` — Images, PDFs, and other files.

### Note types inside `04 - Notes/`

- `Daily Notes/` — One note per day. Capture, plan, reflect.
- `People/` — One note per person you work with.
- `Permanent Notes/` — Evergreen, atomic ideas in your own words.
- `Reference Notes/` — Source material, quotes, and clippings.

## Note Conventions

- Use concise, atomic notes — one idea per note.
- Title notes clearly so they are easy to find and link.
- Link generously. Use `[[wikilinks]]` to connect ideas.
- Use tags for context (e.g., `#project`, `#idea`, `#reference`).
- Daily notes live in `04 - Notes/Daily Notes/`.
- Prefer evergreen notes over one-off summaries.

## Daily Workflow

1. Capture everything into `00 - Inbox/`.
2. Process Inbox items into Projects, Areas, or Resources.
3. Create the morning daily note and link related work.
4. Review the daily note and plan tomorrow.

- **Find & Connect** — surface unexpected links between notes.
- **Suggest & Improve** — propose next actions and cleanups.
