# ventures/

Personal-venture artifacts, kept deliberately **separate** from the CRR /
Education Equity day-job tooling that lives at the repository root.

Nothing in this folder is part of the CRR Document Processing Agent. Treat it
as its own world.

## Contents

- **`ai-skills-library/`** — a vetted collection of Claude/AI agent skills,
  organized into:
  - `active/` — skills reviewed and cleared for direct use
  - `sandboxed/` — third-party skills kept isolated pending or following an
    audit; each carries its own `SOURCE.md` (provenance) and `AUDIT.md`
    (security review notes)

  See `ai-skills-library/README.md` for the catalog and
  `ai-skills-library/SECURITY-AUDIT.md` for the consolidated audit summary.
